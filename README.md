# 테크무진 타임테이블

테크무진 행사 일정을 확인하고, 선택한 세션을 로그인 없이 브라우저 `localStorage`에 저장하는 React 웹앱입니다.

현재 타임테이블은 아래 API를 한 개 트랙 일정으로 해석해 표시합니다.

```text
https://techmujin-api.t-funabiki08.workers.dev/v1/events/techmujin-2026/timetable
```

응답은 Zod로 검증한 뒤 화면에 필요한 형식으로 변환합니다.

## 실행

```bash
pnpm install
pnpm dev
```

타입 검사와 배포용 빌드:

```bash
pnpm typecheck
pnpm build
```

## 다국어 설정

기본값은 일본어 전용입니다. JP/EN/KR 언어 선택기를 활성화하려면 `.env.local` 또는 배포 서비스의 환경변수에 다음 값을 설정합니다.

```env
VITE_ENABLE_I18N=true
```

환경변수가 없거나 `false`이면 일본어만 표시됩니다. Vite 환경변수는 빌드 시점에 반영되므로 값을 변경한 뒤 다시 빌드하거나 배포해야 합니다.

## 디자인 시스템과 색상

조작 버튼, 배지, 알림은 SEED Design을 사용하고 타임테이블 레이아웃은 커스텀 CSS로 구성합니다.

- `tokens.css`: 타이포그래피, 간격, 크기, 모션, 그림자와 시맨틱 색상 연결
- `src/theme.css`: TechMujin 브랜드 색상과 SEED Design 색상 연결
- `src/styles.css`: 화면과 컴포넌트 배치 및 상태 스타일

브랜드 색상을 바꿀 때는 `src/theme.css`의 `--tm-color-*` 토큰만 수정합니다. 보라색과 파란색 그라데이션은 `マイスケジュール`처럼 중요한 동작에만 사용하며, 일반 버튼과 상태 표현은 SEED Design의 브랜드 토큰을 따릅니다.

키보드 포커스는 밝은 안쪽 링과 브랜드색 바깥 링을 함께 사용해 흰색 및 보라색 표면에서 모두 식별할 수 있도록 했습니다. 모바일 터치 조작 요소는 최소 44px 높이를 유지하고, 320px 이상의 화면에서 페이지 자체의 가로 스크롤이 생기지 않도록 합니다. 타임테이블 비교가 필요한 경우에만 표 내부가 독립적으로 가로 스크롤됩니다.

## 일정 저장

사용자가 고른 일정은 세션 객체가 아닌 세션 ID만 아래 키에 저장됩니다.

```text
techmujin:timetable:v3
```

브라우저나 기기가 바뀌면 선택한 일정은 동기화되지 않습니다.

## 캘린더 내보내기

`マイスケジュール` 화면에서 선택한 세션을 하나의 `.ics` 파일로 다운로드할 수 있습니다. 생성 과정은 브라우저 안에서만 처리되며 서버로 선택 정보를 전송하지 않습니다.

파일 공유를 지원하는 모바일 브라우저에서는 `.ics`를 시스템 공유 메뉴로 전달합니다. 공유를 지원하지 않는 환경과 PC에서는 기존처럼 파일을 다운로드하며, 모바일 공유 중 오류가 발생해도 다운로드 방식으로 자동 전환합니다. Web Share API는 HTTPS 환경에서 동작하므로 실제 모바일 테스트는 배포된 미리보기 주소에서 진행해야 합니다.

iPhone과 iPad의 Safari에서는 `Appleカレンダーに追加` 버튼도 표시합니다. 이 버튼은 선택한 세션의 `.ics`를 직접 열어 Apple Calendar의 가져오기 화면으로 이동하며, 최종 추가는 사용자가 확인합니다. iOS Chrome을 포함한 다른 브라우저에서는 기존 `ICSを共有` 또는 다운로드를 사용합니다.

ICS에는 세션 제목, 시작·종료 시각, 발표자, 트랙, 행사 장소와 URL이 포함됩니다. API의 ISO 시각을 UTC로 변환해 Google Calendar와 Apple Calendar 등에서 가져올 수 있도록 구성합니다.

같은 화면에서 선택한 일정을 모바일용 720px 너비의 PNG 이미지로도 다운로드할 수 있습니다. 오전과 오후를 구분해 표시하며, 8개 이하는 1열 상세형, 9개 이상은 3열 압축형으로 자동 전환합니다. 이미지는 브라우저의 Canvas API로 생성하며 외부 프로필 이미지를 포함하지 않아 CORS의 영향을 받지 않습니다.
