# 交通案内の更新

アクセス画面は、地図を最上部に表示し、その下に会場名・住所と交通案内を配置します。交通案内では甲府駅北口からの徒歩・バスを先に掲載し、続いて新宿からの電車と車・駐車場を案内します。徒歩経路、バスのりば・時刻表、駐車場にはそれぞれ直接開けるリンクを設けています。

## 確認した案内（2026-11-10）

- 甲府駅北口から武田通りを北上し、甲府キャンパスまで徒歩約15分。
- バスは甲府駅北口2番のりばから武田神社・積翠寺方面へ乗車し、「山梨大学」で下車。
- 新宿駅から甲府駅までは特急あずさ・かいじで約90分。
- 周辺のコインパーキングを利用。公式イベントサイトでは「ザ・パーク 山梨大学南」を1日500円として案内。
- 満車の場合があるため、できるだけ公共交通機関を利用する。

## 確認元

- [公式イベントサイト・アクセス](https://techmujin.jp/2026/#access)
- [公式イベントサイト・FAQ（駐車場）](https://techmujin.jp/2026/#faq)

## 更新するファイル

- `src/data/access.ts`: 所要時間、のりば番号、駐車料金、外部リンク。
- `src/i18n.ts` の `access.transport`: 日本語・英語・韓国語の案内文。
- `src/components/AccessDirections.tsx`: 表示順序と案内の構成。

交通案内は上記の確認時点の情報を掲載しています。会場内の図面とは別に管理します。
