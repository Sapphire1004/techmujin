# アクセス案内

公式サイトに合わせて、アクセス画面に交通案内とGoogleマップを掲載します。会場の3つのゾーンは会場内マップ画面で別に案内します。公式ソースの確認日：2026-11-12。

## 参照元

- [公式サイト・アクセス](https://techmujin.jp/2026/#access)
- [公式リポジトリ public/2026/index.html](https://github.com/techmujin/techmujin-jp-web/blob/main/public/2026/index.html)

日本語の交通案内とiframeのURLを公式ソースから移植しています。会場内マップに掲載するゾーン名・場所・説明とアイコンも公式ソースに合わせています。レイアウトと色はアプリの既存トークンに合わせています。

## 表示する内容

- PCのアクセス画面は、左にGoogleマップ、右に会場名・住所・交通案内を表示します。モバイルでは地図、会場情報・交通案内の順に縦に並べます。
- 見出しはプログラム画面と共通の文字サイズ・左揃え・説明文のスタイルを使用します。地図と交通案内は淡い背景と紫の交通手段ラベルで公式サイトの構成に合わせます。公式サイトのアクセス案内へのリンクは画面に表示しません。
- 電車：新宿駅から特急あずさ・かいじで約90分「甲府駅」下車。
- 徒歩：甲府駅北口から約15分。
- バス：「甲府駅北口」2番のりばから武田神社・積翠寺方面「山梨大学」下車。
- バス案内は乗り場と行き先を意味のまとまりで分け、幅に余裕がある場合は1行、収まらない場合はまとまりごとに折り返します。
- Googleマップを開くボタンは「アクセス」の見出しと同じ行の右端に配置し、説明文はその下に表示します。320px幅のモバイル画面でも見出しとボタンを横に並べます。
- アクセス・会場内マップはプログラムと別の画面コンポーネントで表示します。タイムテーブルAPIへのリクエストはプログラム画面でのみ開始し、その読み込み待ちや失敗によって会場案内の表示を妨げない構成にします。
- 車：公式サイトと同じく、会場周辺のコインパーキングを利用する旨の基本案内のみ掲載します。
- 会場内マップ画面では、図面の下にステージエリア・ブースエリア・コミュニケーションスペースの紹介を表示します。

## 更新するファイル

- `src/i18n.ts` の `access.transport`：交通案内の日本語・英語・韓国語の表示文。
- `src/i18n.ts` の `venue.zones`：会場内の3つのゾーンの表示文。
- `src/components/AccessDirections.tsx`：アクセス画面の交通案内。
- `src/components/VenueZones.tsx`：会場内マップ画面のゾーン紹介。
- `src/components/VenuePage.tsx`：タイムテーブルAPIに依存しないアクセス・会場内マップ画面。
- `src/data/access.ts`：交通案内の表示順。
- `src/data/venue-map.json` の `venue.mapEmbedUrl`：公式サイトのGoogleマップ iframe URL。

## 駐車場案内の追加対応

駐車場ごとの名称・料金・収容台数や複数地点の地図表示は、[イシュー #28](https://github.com/Sapphire1004/techmujin/issues/28) で別途対応します。料金などの確認日・情報提供元と、利用前に最新の現地表示・運営会社の案内を確認する注意書きもそこで整備します。
