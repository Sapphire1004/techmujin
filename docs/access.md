# アクセス案内

公式サイトのアクセスセクションに合わせて、交通案内・会場の3つのゾーン・Googleマップを掲載します。公式ソースの確認日：2026-11-12。

## 参照元

- [公式サイト・アクセス](https://techmujin.jp/2026/#access)
- [公式リポジトリ public/2026/index.html](https://github.com/techmujin/techmujin-jp-web/blob/main/public/2026/index.html)

日本語の交通案内、ゾーン名・場所・説明、アイコン、iframeのURLを公式ソースから移植しています。レイアウトと色はアプリの既存トークンに合わせています。

## 表示する内容

- 会場名・住所・Googleマップへのリンクを先頭に表示し、地図、交通案内、3つのゾーンの順に表示します。
- 電車：新宿駅から特急あずさ・かいじで約90分「甲府駅」下車。
- 徒歩：甲府駅北口から約15分。
- バス：「甲府駅北口」2番のりばから武田神社・積翠寺方面「山梨大学」下車。
- 車：公式サイトと同じく、会場周辺のコインパーキングを利用する旨の基本案内のみ掲載します。
- ゾーン：ステージエリア、ブースエリア、コミュニケーションスペース。

## 更新するファイル

- `src/i18n.ts` の `access.transport`：公式の日本語案内と英語・韓国語の表示文。
- `src/components/AccessDirections.tsx`：交通案内とゾーン紹介。
- `src/data/access.ts`：案内の表示順と公式サイトへのリンク。
- `src/data/venue-map.json` の `venue.mapEmbedUrl`：公式サイトのGoogleマップ iframe URL。

## 駐車場案内の追加対応

駐車場ごとの名称・料金・収容台数や複数地点の地図表示は、[イシュー #28](https://github.com/Sapphire1004/techmujin/issues/28) で別途対応します。料金などの確認日・情報提供元と、利用前に最新の現地表示・運営会社の案内を確認する注意書きもそこで整備します。
