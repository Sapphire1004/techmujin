# スタンプラリーの試作

このブランチは、完成前の機能を共有し、方向性や操作感のフィードバックを受けるための試作です。現時点ではマージを前提にしていません。

## 現在の仕様

- モバイルファーストのWebアプリとして、会場のQRコードを読み取ってスタンプを集めます。
- 参加操作後にカメラ、またはQR画像のアップロードでスタンプを取得します。手入力による取得機能はありません。
- チェックポイントは仮の5か所です。名称・説明は未確定で、会場案内のブースともまだ連携していません。
- 進行状況は利用中のブラウザーの `localStorage` に保存し、再読み込み時に復元します。
- 同じQRを再度読み取っても、取得数と最初の取得時刻は変わりません。
- 記録のリセット操作は画面に設けていません。
- ログイン、サーバー側の認証、不正取得の防止、景品の交換管理は実装していません。参加者の良識に基づく運用を想定しています。

## ローカルでの確認

依存関係をインストールし、開発サーバーを起動します。

```bash
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1 --port 5176 --strictPort
```

`http://localhost:5176/#stamp-rally` を開き、参加 → QR読み取り → スタンプカードの確認の順に操作します。`#timetable` でタイムテーブルへ戻れます。

既存プロジェクトの `node_modules` を共有しているローカル作業フォルダーでは、依存関係の自動再インストールを避けるため、次の起動コマンドを使用します。

```bash
pnpm --config.verify-deps-before-run=false run dev --host 127.0.0.1 --port 5176 --strictPort
```

カメラを使用するにはlocalhostまたはHTTPSの安全なコンテキストが必要です。スマートフォンで別の端末の開発サーバーを開く場合は、HTTPのLANアドレスではなくHTTPSのプレビュー環境などを使用してください。

## テスト用QR

次のテキストを含むQRコードを使用します。PCではQR画像のアップロードでも確認できます。

```text
stamprally:v1:spot-1
stamprally:v1:spot-2
stamprally:v1:spot-3
stamprally:v1:spot-4
stamprally:v1:spot-5
```

保存キーは `techmujin:stamp-rally:v1` です。同じサイト・同じブラウザーでは記録を引き継げますが、別のブラウザーや端末とは同期されません。サイトデータを削除すると記録も失われます。

## 検証コマンド

```bash
pnpm test:stamp-rally
pnpm typecheck
pnpm build
```

単体テストではNode.js 22.18以降を使用してください。アプリのNode.js要件は `package.json` を参照してください。

## フィードバック・追加確認が必要な項目

- 「ブース訪問・収集・完成」を伝える案内文と参加フロー
- 正式なチェックポイント数・名称・説明
- スマートフォンでのレイアウト、タップ領域、片手操作
- iOS / Android実機でのカメラ許可、QR読み取り、画像読み取り、再訪時の記録復元
- 会場案内ブランチとのナビゲーション統合

現時点の自動検証は型チェック・ビルド・スタンプカードの単体テストです。実機でのカメラや画像読み取りを検証済みとはしていません。
